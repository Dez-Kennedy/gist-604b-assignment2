# Overview  
This repository demonstrates the ability to build data preparation skills, perform real-world analysis workflows, and create professional-quality maps. This repository highlights the flexibility that QGIS provides across platforms. The projects and screenshots provided show analytic ability to perform advanced spatial anaylsis using QGIS.  

The various types of GIS skills practiced in this repository include basic map layouts, visualizing data, working with rasters and vectors, working with attribute tables, map projections, importing CSV spreadsheets, map analysis, and visualizing 3D data.

## Skills Demonstrated
- Using Print Layout for basic map formatting  
- Changing QGIS project variables  
- Creating thematic Maps  
    * Copying/pasting styles between layers  
- Working with coordinate reference systems and reprojecting layers  
- Making basic queries on attributes  
    * Attribute table editing and joins  
- Adding additional columns to a layer's attribute table  
- Using Data Source Manager to import Delimited Text files like CSVs  
- Using expressions to group multiple attribute values into a single category  
- Creating filters to temporarily exclude certain features from computation  
- Creating buffers around points  
- Using expressions to visualize 3D data  

## Reflection
Concepts that became clearer through hands-on work was the [Basic Vector Styling](https://www.qgistutorials.com/en/docs/3/basic_vector_styling.html) tutorial. I could take my ArcGIS workflow and apply it directly to my new workflow. Once I got the basics of styling down, I felt confident tweaking layers to be more pleasing to the eye on a white background. What I found challenging was using new software for GIS analysis. I consider myself a creature of habit, and I have gotten very comfortable navigating ArcGIS. While the workflow in QGIS was fairly similar and at times familiar, using a new tool slowed me down a little, which was frustrating. While I'm unsure how I would personally use these tools, I assume tech start-up companies and private organizations would use this platform. I assumed ArcGIS was the industry standard, but I can see the appeal of using QGIS since it's a free, open-source platform with dedicated tutorials anyone can use.
